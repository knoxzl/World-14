# Starting a ship

Open the G construction menu and build **ship starter lattice** on clear ground
for **10 metal rods**. This makes a separate one-tile shuttle grid, rather than
adding a floor tile to the planet.

Use ordinary metal rods on the ground directly beside the lattice to extend
the same ship. Each extra lattice tile costs the usual one rod. Add floor
plating, walls, machinery, power, thrusters and a shuttle console using normal
SS14 construction. The starter provides the ship's grid; it does not supply
engines or other equipment.

Leave room between separate ships when building. Nearby non-planet grids still
block ambiguous tile placement. Ship extension ignores the underlying planet
for that proximity check, while keeping it as a separate map/grid.

The recipe is in `Resources/Prototypes/_Planet14/shipbuilding.yml`.
